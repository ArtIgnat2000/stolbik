- Не добавлять без отдельного согласования: жизни/сердечки, стресс-таймеры, публичные лидерборды, случайные/платные лутбоксы, родительский ПИН, озвучку/аудиофайлы.
- Каждый PR в `main` увеличивает версию (включая docs/CI), заголовок `v<версия> — …`, заметка `docs/RELEASE-<версия>.md`, версия синхронизирована в `package.json` и `package-lock.json` (`npm version <версия> --no-git-tag-version`).
