# Столбик

Мобильное офлайн PWA-приложение на русском языке для тренировки сложения и вычитания столбиком. Занятие начинается с актуализации знакомой модели и пробного действия: ребёнок объединяет точки и треугольники, исследует разрядные переходы, затем сопоставляет найденный способ с записью столбиком и выполняет самостоятельные задания с самопроверкой. Ошибки объясняются без штрафов, подсказки доступны, а прогресс и профили хранятся локально на устройстве.

Методический ориентир — самое позднее найденное у издателя полное трёхчастное издание Петерсон для 2 класса: углублённый уровень, 2026/2027. Приложение — только модуль по сложению и вычитанию столбиком, а не полный курс и не постраничная копия учебника. ISBN комплекта, методические источники и границы подтверждённого соответствия описаны в [`docs/peterson-methodology.md`](docs/peterson-methodology.md).

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки:

```sh
npm run build
npm run preview
```

Сборка по умолчанию работает в корне сайта. Для GitHub Pages задайте `VITE_BASE`, например:

```sh
VITE_BASE=/stolbik/ npm run build
```

GitHub Actions собирает приложение после push в `main` и в любую Arena-ветку (`arena/**`); в GitHub Pages публикуется только `main`. Адрес сайта: <https://artignat2000.github.io/stolbik/>.

Короткая версия приложения и SHA сборки выводятся в родительском разделе. SHA можно передать через `VITE_COMMIT_SHA` или `GITHUB_SHA`.

## Проверки

```sh
npm run pickup         # зависимости, типы, контент, тесты, сборка и проверка загрузки
npm run content:check  # сэмплирует генераторы всех 13 уровней
npm run test:engine    # арифметика, переносы и займы
npm run test:smoke     # первый запуск, модель разрядов и короткий урок в jsdom
npm run audit:storage  # сохранение профилей и резервные версии IndexedDB
npm run test:boot      # проверка стартовой HTML/PWA-оболочки после сборки
```

## Структура

- `src/content/` — уровни и генераторы корректных примеров.
- `src/engine/` — чистая логика вычислений, пошаговый разбор столбика и построение последовательности разрядных разменов.
- `src/platform/` — IndexedDB, резервные копии, звук и вибрация.
- `src/state/` — типы профиля и Zustand 5 store; компоненты подписываются на отдельные стабильные поля.
- `src/ui/` — экраны, визуализация разрядов, клавиатура и сова БУК.
- `src/tests/` — UI-smoke тесты; unit-тесты находятся рядом с движком и хранилищем.

После первой загрузки app-shell кэшируется service worker'ом. Звуки создаются через Web Audio API, поэтому аудиофайлы и внешние CDN не нужны. IndexedDB хранит профили и ограниченную корзину предыдущих версий; при первом запуске приложение запрашивает постоянное хранение, если браузер поддерживает Storage API.
