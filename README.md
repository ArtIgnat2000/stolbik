# СТОЛБИК — сложение и вычитание столбиком, 2 класс

Мобильное обучающее приложение (PWA) на русском языке для спокойной тренировки **письменного сложения и вычитания столбиком** (двузначные и трёхзначные числа до 1000).
Работает полностью **без интернета**, устанавливается на экран телефона как обычное приложение и разделяет общие интерфейсные решения, сейф прогресса и инженерные практики с проектом **«Слово 2.0»** (`ArtIgnat2000/slovo2`).

Методический ориентир — курс Л. Г. Петерсон для 2 класса (углублённый уровень, 2026/2027). Занятие начинается с актуализации наглядной модели разрядов (точки — единицы, треугольники — десятки, пучки по 10 треугольников — сотни) и пробного действия: ребёнок сам исследует разрядные переходы, сопоставляет найденный способ с записью столбиком справа налево и выполняет самостоятельные задания с самопроверкой. Ошибки объясняются без штрафов, двухступенчатая помощь (наводящий вопрос БУКа → прямая подсказка) доступна всегда, а прогресс и профили хранятся локально на устройстве. Подробнее о методической основе — [`docs/peterson-methodology.md`](docs/peterson-methodology.md).

## Запуск и проверки

```bash
npm install
npm run pickup         # «поднять сессию»: починить историю git, npm ci при нужде, прогнать контур проверок
npm run dev            # разработка (0.0.0.0:5173)
npm run build          # прод-сборка (dist/)
npm run preview        # посмотреть прод-сборку
npm run preview:build  # сборка с базой / в папку preview/
npm run typecheck      # проверка типов TypeScript
npm run test:release   # юнит-тесты правил релиза (scripts/release-check.test.mjs)
npm run release:check  # сверка версии, package-lock.json, заметки docs/RELEASE-<версия>.md и заголовка PR
npm run content:check  # сэмплирует генераторы всех 13 уровней
npm run test:engine    # тесты арифметики столбика, разрядов и генератора QR/PNG
npm run test:smoke     # смоук- и UI-тесты в jsdom: первый запуск, урок, разделы, сейф, QR и обновление
npm run audit:storage  # проверка сейфа прогресса: профили, снимки, корзина, резервные копии
npm run test:boot      # проверка стартовой HTML/PWA-оболочки и размера JS-бандла (< 200 КБ)
npm run test:qr        # внешняя проверка QR-кода через jsqr и qrcode (нужно npm i --no-save qrcode jsqr)
```

Сборка по умолчанию работает в корне сайта. Для GitHub Pages задайте `VITE_BASE`:

```bash
VITE_BASE=/stolbik/ npm run build
```

Адрес опубликованного сайта: <https://artignat2000.github.io/stolbik/>.

## Версии и релизы (единый стандарт со «Слово 2.0»)

* Номер релиза — поле `version` в `package.json`. **Каждый PR в `main` увеличивает версию**, включая документацию и CI. Исключений «без релиза» нет.
  Версии в `package.json` и `package-lock.json` (верхняя и `packages[""]`) должны совпадать — поднимайте версию командой:
  ```bash
  npm version <версия> --no-git-tag-version
  ```
* **Заголовок каждого PR начинается с номера релиза**: `v0.2.0 — краткое описание`. Обязательна заметка `docs/RELEASE-<версия>.md`.
* **Описание PR** заполняется по шаблону `.github/pull_request_template.md`.
* CI (`.github/workflows/check.yml`) выполняет `npm run test:release` и `npm run release:check`: версия должна быть строго больше версии текущего `main`, `package-lock.json` и релизная заметка согласованы, заголовок PR соответствует версии. Локальная проверка: `npm run release:check -- origin/main`.
* Каждая сборка помечается коротким SHA коммита (`__APP_VERSION__` и `__COMMIT_SHA__`). В приложении версия и сборка видны в разделе **«Родителям → Приложение»** и в нижней строке экрана выбора профиля: `v0.2.0 · 2ff9e4e4`.

## Известные грабли

### 1. Пустой экран на Pages (`Minified React error #185`)
Селектор Zustand 5 передаётся напрямую в `useSyncExternalStore` и сравнивается по ссылке (`Object.is`). Если селектор возвращает новый объект или массив на каждый вызов (`?? {}`, `?? []`, `.filter(...)`), React уходит в бесконечный цикл перерисовок на первом запуске. Всегда подписывайтесь на примитивные/стабильные поля стора или выносите пустые значения в константы модуля.

### 2. Пересоздание рабочей копии в песочнице
Клон песочницы периодически пересоздаётся от точки форка (`node_modules` стираются, история `shallow`). Команда `npm run pickup` (`scripts/pickup.mjs`) в один шаг:
1. Делает `git fetch` и, если локальный `HEAD` отстал от `origin/<ветка>` без локальных коммитов впереди, выполняет `git reset --mixed origin/<ветка>` (сохраняя страховочную ссылку `refs/pickup-backup/<ветка>` и **не трогая** рабочее дерево);
2. Ставит зависимости через `npm ci`, если `node_modules` отсутствуют;
3. Прогоняет полный контур проверок (`typecheck`, `content:check`, `test:engine`, `audit:storage`, `test:smoke`, `build`, `test:boot`) и печатает последнюю точку передачи из `docs/PLAN.md`.

### 3. Принудительная тёмная тема на Android и QR-код
Некоторые мобильные браузеры (например, Samsung Internet с принудительным Force Dark) инвертируют цвета SVG-элементов, из-за чего SVG QR-код превращается в нечитаемый серый квадрат. Поэтому QR-код в `src/engine/qrPng.ts` рендерится как **растровая 1-битная чёрно-белая PNG-картинка** — пиксели изображения не перекрашиваются браузером.

## Разделы программы

Нижняя навигация на основных экранах содержит четыре раздела:
* **📚 Уроки** — главная страница: карточка следующего шага, кнопка **«🤝 Позови друга»**, полоска активности за 7 дней, задания дня с наградой в кристаллах 💎 и все 13 уровней курса.
* **📖 Темы** — **Справочник тем**: наглядная памятка разрядов (сотни, десятки, единицы), фильтры (*«Все 13»*, *«Сложение»*, *«Вычитание»*, *«До 1000»*, *«Освоено»*) и карточки всех 13 тем. Нажатие на любую тему открывает подробный пошаговый разбор опорного примера в столбик (`ColumnDisplay`) с кнопкой перехода к занятию.
* **🦉 БУК** — гардероб аксессуаров и цветов для совы БУК за заработанные кристаллы 💎.
* **🔒 Родителям** — защищённый примером для взрослых раздел из четырёх вкладок:
  * 📊 **Обзор** — быстрые кнопки (*«💾 Сохранить в файл»*, *«📲 Поделиться QR»*, *«🔄 Проверить обновление»*), сводка за неделю и прогресс по всем 13 уровням;
  * 💾 **Прогресс** — сейф прогресса: сохранение и загрузка резервной копии (один или все профили), статус хранилища и запрос защиты от автоочистки браузером, автоматические и ручные снимки **«Вернуть как было»** (до 10 слотов), **корзина удалённых профилей** (хранится 30 дней с полным восстановлением корон и кристаллов), журнал событий и опасная зона со сбросом;
  * ⚙️ **Настройки** — цель на день, спокойный режим, показ переноса и займа, видимость совы БУК (*«Везде»*, *«На главной»*, *«Скрыть»*), звук и вибрация;
  * 📲 **Приложение** — карточка **«Обновление программы»** с кнопкой проверки обновления, карточка **«Передать приложение»** с масштабируемым QR-кодом, инструкция по установке на экран телефона и сведения о версии/SHA сборки.

## Передача ссылки и обновление приложения

* **Как поделиться приложением:**
  * Кнопка **«🤝 Позови друга»** в шапке главного экрана открывает лист с крупным QR-кодом и кнопками отправки/копирования ссылки.
  * Карточка **«Передать приложение»** доступна в разделе «Родителям → Приложение» и в компактном виде на экране выбора профиля («Кто сегодня будет считать?»).
  * При сборке под фиксированный домен адрес можно задать через `VITE_PUBLIC_URL=https://... npm run build`.
* **Автоматическое и ручное обновление PWA:**
  * Приложение автоматически проверяет наличие новой версии при запуске, каждые 30 минут и при возвращении во вкладку, показывая сверху плашку **«Доступно обновление → Обновить»**.
  * Проверить и установить обновление вручную можно кнопкой **«🔄 Проверить обновление»** в разделе «Родителям → Обзор», в карточке «Обновление программы» («Родителям → Приложение») или в нижней панели экрана выбора профиля.
